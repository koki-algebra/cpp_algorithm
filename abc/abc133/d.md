# ABC133 D - Rain Water Bucket

- 問題: <https://atcoder.jp/contests/abc133/tasks/abc133_d>

## 問題の言い換え

- 円環状に並んだ $N$ 個の山(山 $1, \dots, N$)と、その間にある $N$ 個のダム(ダム $1, \dots, N$)がある。$N$ は奇数。
- 山 $i$ に $2x$ リットルの雨が降ると、ダム $i-1$ とダム $i$(添字は $\mathrm{mod}\ N$)にそれぞれ $x$ リットルずつ水が溜まる。
- 各ダムの貯水量 $A_1, \dots, A_N$ が与えられるので、各山に降った雨量を求めよ。
- 制約下では解が一意に定まることが保証されている。

## 解法の考え方

山 $i$ に降った雨量を $2b_i$ とおく($b_i$ は「片側のダムに配られる分の雨量」)。すると、ダム $i$ の貯水量について次の関係が成り立つ(添字は $1$〜$N$ の巡回、$A_{N+1} = A_1$、$b_{N+1} = b_1$)。

$$A_i = b_i + b_{i+1} \quad (i = 1, \dots, N)$$

これは $N$ 元の巡回連立一次方程式であり、$N$ が**奇数**であることが解の一意性・求め方の鍵になる。

交互に符号を変えて全ての式を足し合わせると、$b_2, \dots, b_N$ がきれいに打ち消し合い、$b_1$ だけが残る。

$$A_1 - A_2 + A_3 - A_4 + \cdots + A_N = 2b_1$$

($N$ が奇数なので最後の項 $A_N$ の符号がちょうど $+$ になり打ち消し合いが成立する。$N=3$ で検算すると $A_1 - A_2 + A_3 = (b_1+b_2) - (b_2+b_3) + (b_3+b_1) = 2b_1$ で確認できる。)

$b_1$ が求まれば、あとは定義式 $A_i = b_i + b_{i+1}$ を使って

$$b_{i+1} = A_i - b_i \quad (i = 1, \dots, N-1)$$

と芋づる式に全ての $b_i$ が計算できる。答えは各山について $2b_i$。

## 実装イメージ

`template.cpp` で定義済みの include・using・マクロは省略。

```cpp
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    ll n;
    cin >> n;
    vl a(n);
    rep(i, n) cin >> a[i];

    // 2*b_1 = A_1 - A_2 + A_3 - ... + A_N (交互和)
    ll sum2b1 = 0;
    rep(i, n) sum2b1 += (i % 2 == 0 ? a[i] : -a[i]);
    ll b1 = sum2b1 / 2;

    vl b(n);
    b[0] = b1;
    rep2(i, 1, n) b[i] = a[i - 1] - b[i - 1];

    rep(i, n) cout << 2 * b[i] << (i + 1 < n ? ' ' : '\n');

    return 0;
}
```

## 計算量

$O(N)$。$N \le 10^5$ 程度の制約に対して十分高速。

## 注意点

- $A_i \le 10^9$、$N \le 10^5$ 程度なので、交互和の絶対値は最大 $10^{14}$ 程度になり得る。`int` ではオーバーフローするため `ll`(`long long`)で計算する必要がある。
- 解の一意性が保証されているため、交互和による構成をそのまま実装すれば正しい解が得られる(非負性などの検証は不要)。
