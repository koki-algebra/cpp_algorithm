# ABC136 D - Gathering Children

- 問題: <https://atcoder.jp/contests/abc136/tasks/abc136_d>

## 問題の言い換え

- `L` と `R` のみからなる長さ $N$ の文字列 $S$ が与えられる($2 \le N \le 10^5$)。$S$ の1文字目は必ず `R`、$N$文字目は必ず `L`。
- $N$ 個のマスが一列に並び、マス $i$ には最初 $1$ 人の子供がいる。
- 各子供は「今いるマスの文字に従って1マス移動する」($\verb|R|$ なら右、$\verb|L|$ なら左)を $10^{100}$ 回繰り返す。
- $10^{100}$ 回の移動後、各マスに何人いるかを求めよ。

## 解法の考え方

`R` のマスにいる子供は右へ、`L` のマスにいる子供は左へしか進まない。したがって子供が動ける範囲は「隣り合う1つの `R` の連続区間(以下 **Rラン**)とその右にある1つの `L` の連続区間(以下 **Lラン**)」の内部に閉じている。

Rランの最後のマスは `R`(右へ進む)、その右隣であるLランの先頭マスは `L`(左へ進む)なので、この2マスの間だけは永久に

$$\text{Rランの最後のマス} \longrightarrow \text{Lランの先頭マス} \longrightarrow \text{Rランの最後のマス} \longrightarrow \cdots$$

と周期2で振動し続ける。$10^{100}$ 回という莫大な回数の移動の後には、各子供はこの「境目の2マス」のどちらかに落ち着いている。

そこで $S$ を

$$\underbrace{R \cdots R}_{a}\ \underbrace{L \cdots L}_{b}\ \underbrace{R \cdots R}_{a'}\ \underbrace{L \cdots L}_{b'}\ \cdots$$

のように `R` のランと `L` のランの並び(ランレングス圧縮)に分解し、隣接する $(a, b)$ の組ごとに独立に人数を計算すればよい。

### 1ブロック内での人数の求め方

Rラン(長さ $a$)の右端から数えて距離 $d\ (d = 0, 1, \dots, a-1)$ にいる子供を考える。この子供は $d$ 回移動でRランの最後のマスに到達し、以後は境目の2マスを周期2で往復する。$10^{100}$ は偶数なので、最終的にいるマスは $d$ の偶奇だけで決まる。

- $d$ が偶数 → 最終的に **Rランの最後のマス** に落ち着く
- $d$ が奇数 → 最終的に **Lランの先頭マス** に落ち着く

$d = 0, \dots, a-1$ のうち偶数の個数は $\lceil a/2 \rceil$、奇数の個数は $\lfloor a/2 \rfloor$。

Lラン(長さ $b$)側も対称に、先頭から数えて距離 $d'\ (d' = 0, \dots, b-1)$ の子供は、$d'$ が偶数なら **Lランの先頭マス**、奇数なら **Rランの最後のマス** に落ち着く。

以上より

$$
\begin{aligned}
\text{Rランの最後のマスの人数} &= \lceil a/2 \rceil + \lfloor b/2 \rfloor = (a+1)/2 + b/2 \\
\text{Lランの先頭のマスの人数} &= \lfloor a/2 \rfloor + \lceil b/2 \rceil = a/2 + (b+1)/2
\end{aligned}
$$

(いずれも整数除算)。ブロック内のそれ以外のマスの人数は全員この2マスのどちらかへ流れ込むため $0$ になる。

## 実装イメージ

`template.cpp` で定義済みの include・using・マクロは省略。

```cpp
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;
    ll n = s.size();

    vl ans(n, 0);
    vl div = {0};
    for (int i = 0; i < n;) {
        ll j = i;
        while (j < n && s[j] == s[i]) j++;
        div.push_back(j);

        if (s[i] == 'L') {
            ll m = div.size();
            ll a = div[m - 2] - div[m - 3];
            ll b = div[m - 1] - div[m - 2];
            ans[i - 1] = (a + 1) / 2 + b / 2;
            ans[i]     = a / 2 + (b + 1) / 2;
        }
        i = j;
    }

    rep(i, n) cout << ans[i] << " \n"[i + 1 == n];

    return 0;
}
```

`div` には各ランの終端インデックス(exclusive)を順に積んでいく。$S$ は必ず `R` で始まり `L` で終わるので、ランは $R, L, R, L, \dots$ と交互に現れ、今のランが `L` である時点(`s[i] == 'L'`)では

- `div[m-3]` = 直前のRランの開始位置
- `div[m-2]` = 直前のRランの終端 = 今のLランの開始位置(`i` と一致)
- `div[m-1]` = 今のLランの終端(`j`)

を指しているので、`a = div[m-2] - div[m-3]` が直前のRランの長さ、`b = div[m-1] - div[m-2]` が今のLランの長さになる。`i - 1` が「Rランの最後のマス」、`i` が「Lランの先頭のマス」に対応するので、そのまま上の式を `ans[i-1]`, `ans[i]` へ書き込む。

## 計算量

各文字を1回ずつ見るだけなので $O(N)$。$N \le 10^5$ に対して十分高速。

## 検証(サンプル1: `RRLRL`)

1ブロック目 `RR|L`($a=2,\ b=1$)

- Rランの最後(index 1): $(2+1)/2 + 1/2 = 1 + 0 = 1$
- Lランの先頭(index 2): $2/2 + (1+1)/2 = 1 + 1 = 2$

2ブロック目 `R|L`($a=1,\ b=1$)

- Rランの最後(index 3): $(1+1)/2 + 1/2 = 1 + 0 = 1$
- Lランの先頭(index 4): $1/2 + (1+1)/2 = 0 + 1 = 1$

index 0 はどのブロックの境目にも該当しないため $0$ のまま。

結果: `0 1 2 1 1` → サンプル出力と一致する。

## 注意点

- $S$ が必ず `R` で始まり `L` で終わるという制約により、「`L` のランの前には必ず `R` のランが存在する」($a \ge 1$)ことが保証されるため、`div[m-3]` への参照が範囲外になることはない。
- `div` を書き換えず `push_back` のみで管理し、差分 `div[m-1] - div[m-2]` として区間長を取り出す点がポイント。
